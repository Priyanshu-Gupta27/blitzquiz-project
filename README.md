# ⚡ blitzquiz ⚡

A premium, modern coding competition platform landing page built with **Next.js 15**, **TypeScript**, and **Vanilla CSS**.

![blitzquiz Preview](https://github.com/curiousrajneesh27/blitzquiz/raw/main/public/next.svg) *Add your screenshot here after deployment*

## 🚀 Features

- **Premium Dark UI**: A sleek, high-contrast dark theme by default, inspired by high-end developer tools.
- **Dynamic Theme Switching**: Seamlessly toggle between **Light** and **Dark** modes with persisted user preference.
- **High Performance**: Built with Next.js App Router and optimized with Vanilla CSS Modules for zero runtime CSS overhead.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.
- **Active Contests Section**: Live-updating contest cards with clean "DEV" badges and clear calls to action.
- **Modern Landing Sections**:
  - Left-aligned Hero with premium typography.
  - Interactive Stats section showing platform growth.
  - Four-column "Why blitzquiz?" features grid.
  - "Ready to Compete" CTA and a detailed footer.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [CSS Modules](https://github.com/css-modules/css-modules) / [Next Themes](https://github.com/pacocoursey/next-themes)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: [Geist](https://vercel.com/font) (Modern Sans-serif)

## 📦 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/curiousrajneesh27/blitzquiz.git
   cd blitzquiz
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   npm run start
   ```

## 🎨 Design Philosophy

BlitzQuiz follows a minimalist yet premium aesthetic. We use subtle gradients, glassmorphism (blurred backgrounds), and consistent section dividers to create a sense of depth and hierarchy. The typography is scaled down purposefully for a lighter, more sophisticated feel.
